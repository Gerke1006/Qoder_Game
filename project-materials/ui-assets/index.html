UI 素材交付验收

依照样例风格图手绘质感制作：厚描边、羊皮纸与木质底板、糖果光泽。全部为带透明通道的 PNG， 按 960×540 设计分辨率定尺寸，面板支持九宫格拉伸，可直接接入 Phaser 3 工程。

09

面板类

通用面板底板（九宫格）与通用小面板底板。四角与四边厚度一致，拉伸时只缩放中心区域，角饰不变形。

九宫格拉伸实验台

拖动滑杆实时拉伸：四角保持原始比例，仅中心羊皮纸区域伸缩。接入代码 add.nineslice(x,y,key,null,w,h,64,64,64,64)。

10

进度条类

底槽、填充、边框三层分离：底槽垫底、填充按血量比例裁切、镂空边框盖顶，任意血量都不会露出毛边。

11

通用图标

金币、基地 / 心形、伤害、攻速、时间、波次，另附防御盾图标备用。统一 128×128 透明画布，HUD 中缩至 32–48px 依旧清晰。

HUD 尺寸预览

滑杆同时作用于上方图标卡片与 HUD 模拟行，检查小尺寸下的描边与辨识度。推荐 HUD 用 36px、结算界面用 64px。

稀有度相关

普通 / 稀有 / 史诗三档卡牌边框，中心镂空、顶部留空白铭牌，游戏内自行叠加图标与文字即可组成强化卡。

强化卡组装演示 · 点击选择

边框为纯框体素材：铭牌文字、卡面底色与图标均由代码层叠加，换文案不用改图。

史诗框自带紫色辉光，稀有框带冷蓝辉光，普通框无辉光——与样例图的三档视觉层级一致。点击卡片试试选择反馈。

Phaser 3 接入指南

素材目录结构与工程约定一致：整体拷入 assets/ui/ 即可，manifest.json 内含全部尺寸与九宫格参数。

复制即用代码
// Preload 场景：按 manifest 批量加载
for (const [key, info] of Object.entries(manifest.assets))
  this.load.image(key, info.file);

// 面板：九宫格拉伸，角饰不变形
this.add.nineslice(480, 270, 'panel_main', null, 640, 360, 64, 64, 64, 64);
this.add.nineslice(x, y, 'panel_small', null, w, h, 16, 16, 16, 16);

// 血条：三层组装，填充按比例裁切
const trough = this.add.image(x, y, 'bar_trough').setOrigin(0);
const fill   = this.add.image(x + 17, y + 13, 'bar_fill').setOrigin(0);
const frame  = this.add.image(x, y, 'bar_frame').setOrigin(0);
const setHp = r => fill.setCrop(0, 0, 447 * r, 32);

// 飘字：上浮 + 弹性缩放后销毁
const t = this.add.image(ex, ey, crit ? 'dmg_crit' : 'dmg_normal');
this.tweens.add({ targets: t, y: ey - 90, scale: { from: .6, to: 1 },
  alpha: { from: 1, to: 0 }, duration: 900, ease: 'Cubic.Out',
  onComplete: () => t.destroy() });
下载 manifest.json

命名约定：文件名即纹理 key，与 manifest 一一对应，三人协作时不要改名。

缩放建议：图标源 128px，HUD 显示 36px；面板源 512px，按九宫格参数拉伸到任意尺寸。

飘字：素材为样式样板（128 / 512! / -20），实战数字建议用同款描边字体动态渲染，风格保持一致。
